# Software / Programming

BARONDUINO EVERYはArduino Nano Everyのソフトウェア資産の活用を目標としています。

HEADにはATmega4809を搭載し、BODYはUSB-CとCH552Gを用いてプログラム書き込み用インターフェースを提供する設計です。

## 開発中の書き込みと、組込み後の書き込み

開発時はHEADをBODYに接続して書き込む構成を想定しています。一方、**HEADを機器へ埋め込んだ後も、表面のGND / UPDI / RX / TXデバッグ端子を使ってファームウェアの修正・書き換えを繰り返せる設計**です。最終ファームウェアを組込み前に確定することを前提としていません。

具体的な配線、使用する書き込み機器・ソフトウェア、実機での確認手順は検証後に公開します。
