# Software / Programming

BARONDUINO EVERYのソフトウェアは、**HEADのArduino Nano Every互換性**と、**BODYによる書き込み・シリアル通信機能**の2つに分けられます。

## HEAD — Arduino Nano Every互換

HEADはATmega4809を搭載し、Arduino Nano Everyとの互換性を重視しています。

| 互換性 | 内容 |
| --- | --- |
| **バイナリ互換** | Arduino Nano Every向けにビルドしたプログラムをHEADでも使用できる設計 |
| **コード互換** | Arduino Nano Every向けのソースコードを、変更や再移植なしで利用できる設計 |
| **ピン互換** | Arduino Nano Everyと同じピン番号・機能の対応を維持する設計 |

HEADを小さくしても、Nano Every向けに蓄積されたソフトウェア資産を活用できることを目指しています。

※互換性は設計上の目標・仕様です。対応するボード設定、ヒューズ設定および実機での互換性確認は、検証結果に応じて追記します。

## BODY — HEADへの書き込み・シリアル通信

BODYは、USB Type-CとCH552Gを備えた**書き込み・シリアル通信用インターフェース**です。BODY側の専用ソフトウェアによって、HEADへのSerialUPDIによるプログラム書き込みとUSBシリアル通信（Arduino IDEのシリアルモニタ等）を行う構成です。

HEADの埋め込み前後で、使用するBODYは同じです。接続する端子が異なります。

| HEADの状態 | BODYとの接続 |
| --- | --- |
| **埋め込み前** | HEAD裏面5接点とBODYのポゴピン |
| **埋め込み後** | BODYのJ2（1～4番：GND / UPDI / RXout / TXin）からHEAD表面4端子（GND / UPDI / RX / TX） |

これにより、HEADを機器へ埋め込んだ後も、BODYを介してファームウェアの修正・書き換えを継続できます。別種の専用書き込み装置を前提とするものではありません。なお、ブレークポイント設定やステップ実行などのオンチップデバッグには対応していません。

※具体的な書き込み・シリアル通信機能、接続手順および専用ソフトウェアの提供内容は、実機検証後に詳細を掲載します。
